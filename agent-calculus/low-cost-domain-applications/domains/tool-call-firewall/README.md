# Tool-call firewall

A support copilot may request only an opaque, one-use capability for one exact
read-only order lookup. Ticket and order IDs are closed registry values, while
mutating operations are rejected before System One.

SHACL closes the request and the independently observed support-ticket record.
SROIQ proves caller eligibility, order and operation classifications, ticket
assignment, and issuer support. Deterministic policy fixes the HTTP method,
path, purpose, one-use limit, and 60-second lifetime.

The effect returns a simulated attenuated-capability receipt. It does not issue
credential material or invoke the order service.
