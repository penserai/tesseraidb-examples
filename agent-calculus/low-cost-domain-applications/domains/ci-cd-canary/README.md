# CI/CD canary deployment

This pack models a bounded production canary for one signed build of the
checkout service. Closed harvesters resolve the registered build, change,
service, environment, controller, rollout, and five-percent ring; an unknown
identifier or a request to bypass tests rejects before System One.

Closed SHACL validates the complete request and independent release evidence,
including the immutable commit, signature, test status, coverage, vulnerability
count, controller, change, and timestamp. SROIQ proves release authority and
the service, controller, environment, and change-to-artifact relationships.
Deterministic policy enforces all remaining release thresholds.

The effect is simulation-only: it emits a proof-bound deployment proposal with
`deployment_started: false`. A generative model never participates in control.
